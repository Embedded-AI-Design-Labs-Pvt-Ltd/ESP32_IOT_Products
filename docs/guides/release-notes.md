# Release notes 1.0.0

Initial reusable ESP32-C3 IoT platform: HAL/drivers, FreeRTOS OSAL, Wi-Fi, NimBLE GATT, MQTT TLS, OTA rollback, diagnostics, ten product profiles, host simulation GUI, Docker (IDF + sim), Jenkins CI.

Not a certified energy meter, charger safety controller, or vehicle ECU.
