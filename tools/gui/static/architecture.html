stateDiagram-v2

  WIFI_CONNECTING --> WIFI_CONNECTED: STA_CONNECTED

  WIFI_CONNECTING --> WIFI_ERROR: set_config fail

OTA + rollback

sequenceDiagram
  participant C as Cloud
  participant M as MQTT/cmd
  participant O as ota task
  participant B as otadata
  C->>M: {"ota_url":"https://..."}
  M->>O: iot_ota_start https only
  loop download
    O->>O: esp_https_ota_perform + WDT pet
  end
  alt complete
    O->>B: switch slot
    O->>O: esp_restart
    Note over O: app_main calls mark_valid
  else fail
    O->>B: abort — previous slot bootable
  end

Fault recovery

flowchart TD
  F[Fault] --> W{Watchdog?}
  W -->|task/int WDT| R[Panic reboot + DIAG_WATCHDOG_RESET]
  W -->|Wi-Fi drop| B[WIFI_RECONNECTING exponential backoff]
  W -->|MQTT drop| Q[IDF client reconnect 5s]
  W -->|sensor timeout| D[DIAG_SENSOR_TIMEOUT drop sample]
  W -->|bad command| X[IOT_ERR_DENIED no actuator]
