POSIX / host simulation

On host, iot_rtos.c maps tasks to Win32 threads or POSIX pthreads, mutexes to CreateMutex/pthread_mutex, and queues to a bounded ring with semaphores. This is the no-hardware virtual path used by Docker Dockerfile.sim and tests/host.
